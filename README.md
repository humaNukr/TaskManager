# KMA TaskManager

`KMA TaskManager` — багатошаровий застосунок для керування проєктами та завданнями на .NET MAUI.  
Проєкт реалізує повний цикл роботи з даними: перегляд, пошук, сортування, створення, редагування та видалення збережених сутностей.

## Технології

- .NET 9
- .NET MAUI (Windows + Android target frameworks)
- SQLite (`SQLiteAsyncConnection`)
- CommunityToolkit.Mvvm
- xUnit + Moq

## Функціонал

### Проєкти (сутність 1-го рівня)
- список усіх проєктів;
- пошук за назвою;
- фільтрація за статусом (усі / в процесі / завершені);
- сортування (назва, прогрес);
- створення, редагування, видалення;
- перегляд детальної інформації.

### Завдання (сутність 2-го рівня)
- список завдань у межах проєкту;
- пошук за назвою;
- фільтрація/сортування (активні, завершені, критичні, найближчий дедлайн);
- створення, редагування, видалення;
- перегляд детальної інформації;
- розрахунок ознаки простроченості.

## Архітектура рішення

Рішення поділене на окремі проєкти з чіткими зонами відповідальності:

- `TaskManager.Maui` — UI, сторінки, ViewModel-и, навігація.
- `TaskManager.Services` — бізнес-логіка та мапінг `DataModel -> DTO`.
- `TaskManager.Repositories` — абстракція доступу до сховища.
- `TaskManager.Storage` — реалізація контексту SQLite та ініціалізація даних.
- `TaskManager.DataModels` — моделі зберігання.
- `TaskManager.DTOModels` — моделі для UI/передачі даних.
- `TaskManager.CreateModels` / `TaskManager.EditModels` — моделі для введення та валідації.
- `TaskManager.Common` — спільні enum-и та допоміжні утиліти.
- `KMA.TaskManager.Tests` — юніт-тести.

## Принципи

- MVVM для UI-логіки.
- IoC/DI через `MauiProgram`.
- Взаємодія UI тільки через сервісний шар.
- Асинхронні операції доступу до сховища.
- Одне головне вікно та Shell-навігація між сторінками.

## Сховище даних

- Використовується локальна SQLite база.
- Файл БД створюється в `LocalApplicationData/DB Storage/task_manager.db3`.
- Під час першого запуску виконується первинне заповнення тестовими даними.
- При видаленні проєкту видаляються і пов’язані завдання.

## Запуск

1. Відкрити `TaskManager.sln`.
2. Відновити пакети:
   - `dotnet restore`
3. Запустити застосунок:
   - через IDE (Windows/Android),
   - або `dotnet build TaskManager.sln`.

## Тести

- Запуск всіх тестів:
  - `dotnet test TaskManager.sln`

На поточному стані проєкту всі юніт-тести проходять успішно.
